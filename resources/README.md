# Packaged app resources

- `icon.png` — generated by `npm run icon` (`scripts/write-icon.mjs`). Do not hand-edit.
- `entitlements.mac.plist` / `entitlements.mac.inherit.plist` — hardened-runtime
  entitlements used by signed macOS release builds. Local `package:mac` builds
  explicitly disable signing and hardened runtime.
