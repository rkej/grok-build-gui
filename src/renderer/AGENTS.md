# Renderer

- Preserve Codex-style information architecture: conversation first,
  compact type, hairline elevation.
- Talk to main only through `window.grokApp`. Do not import Node modules.
- The 768px transcript column is centered in the main pane; the scrollbar
  belongs on the full-width timeline pane, not the reading column.
- The composer plan strip stays visible while a plan has unfinished tasks;
  historical plans stay in the timeline as plan cards.
